# Portal de Gamificación SENA

Repositorio central del portal gamificado de electrónica y automatización y sus juegos educativos.

## Proyectos incluidos

- `index.html`: portal principal.
- `juegos/desafio-industrial/`: Maestro de la Planta / Desafío Industrial.
- `juegos/ruleta-resistencias/`: Ruleta de Resistencias.
- `juegos/mision-componentes/`: Misión Componentes, con música de fondo y premio SENA de vida extra cada 30 segundos.

## Publicación

El contenido es estático y compatible con Vercel. Cada juego conserva su despliegue de producción actual; este repositorio funciona como respaldo central y fuente para conectar futuras publicaciones automáticas.

Repositorio conectado con Vercel para despliegues automáticos desde la rama `main`.
